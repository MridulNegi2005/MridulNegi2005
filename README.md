I build things and keep them running.

My longest-running project is **[Cosmic Bot](https://github.com/MridulNegi2005/royalbot)** — a Discord bot I've written and maintained **entirely myself since 2021**. It's grown to **6,000+ lines across 25 modules**: a Lavalink-powered music engine, a leveling system with Pillow-rendered rank cards, moderation tooling, and a database layer I migrated from synchronous to fully async PostgreSQL. It's run a live community every day for years — bugs, refactors, and all.

Right now I'm going deep on **backend engineering** (Python, async, databases) and poking at **ML/LLMs** on the side.
